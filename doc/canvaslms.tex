% The chapters cross-reference each other's subsubsections with \cref: the
% rename-matching rule, the completion requirements in module specs and the
% cache TTL constants are all pointed at from other chapters.  A \label on an
% unnumbered heading has no number of its own to bind to, so it silently
% picks up the enclosing subsection's, and \cref then prints that
% subsection's number for a subsubsection pages away---every subsubsection of
% one subsection rendering as the same reference.  didactic.sty numbers down
% to subsection, so this must come after it is loaded; going one level deeper
% gives every referenced heading its own counter, which repairs all such
% references at once and keeps future ones correct.  The table of contents is
% deliberately left alone at didactic's \maxtocdepth{subsection}: numbering a
% heading and listing it are separate decisions, and 89 more entries would
% only bloat the contents.
\setsecnumdepth{subsubsection}
